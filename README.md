# KJV Reader

An offline King James Bible reader for Android. The Bible text, Strong's
dictionary, Webster's 1828 definitions, cross-references and quotation index are
all bundled in the APK. No network permission, no ads, no analytics.

**The Android app is the finished product.** The browser version in `web/` is an
early work in progress that lags well behind it: it reads the same data and does
the reading, word study and notes, but folders, history, search refinements,
read-aloud and cross-references are not there yet. Treat it as a preview, not as
the app.
